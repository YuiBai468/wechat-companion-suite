# 发布验证

此版本从源码白名单创建干净提交历史，未复用个人仓库 Git 历史。

## 已实际完成

- 发布文件的通用密钥、私人路径及已知个人内容负向检查。
- Python 源码编译、离线后端测试与隐私扫描器测试。
- 使用假机器人、临时端口验证本机控制台访问限制与健康令牌校验。
- 示例配置和 `--help` 检查，不连接微信或模型服务。
- 看板源码构建、既有界面元素保留检查，以及合成数据界面预览。
- Windows 本机编译 SessionBackend、ChildProbe、启动器和 OpenCompanion；纯隔离判断测试 14 项通过。未启动公开副本的微信或会话。
- 在发布副本上独立复跑既有后端回归 99 项通过；历史测试的本机路径适配只保留在发布工作区外。

## 验证范围

手机应用保留完整跟踪源码、健康推送和设备支持改动。当前电脑本地 Gradle 在创建文件哈希缓存目录时失败，尚未进入 Android 源码编译，因此**不宣称 APK 构建或手机安装验证通过**。仓库内 Android 工作流可手动运行检查；结果以 GitHub Actions 具体运行记录为准。

微信登录、真实模型请求、蓝牙设备配对与真实健康数据不参与公开版离线测试。首次部署需使用者自己的账号、密钥和设备完成实际检查。依赖版本和服务商模型可用性由使用者部署环境决定。

## 持续检查

`Verify source` 工作流检查跟踪文件、隐私扫描器、Python 源码和生成看板是否一致；Android 工作流只做源码构建，不上传手机数据或签名文件。发布前还会比对远端 Git 文件树与脱敏发布清单的逐文件哈希。
