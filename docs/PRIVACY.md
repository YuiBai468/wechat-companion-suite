# 隐私设计与发布边界

## 公开源码与本地数据

源码和示例配置可以公开分享。实际运行时生成的聊天上下文、记忆、事实、承诺、健康测量、照片、日志、模型原文和设备状态保存在本地数据目录。

默认示例不包含可用账号、服务商密钥、健康令牌或聊天对象。运行者填写自己的配置后启用相应功能。

本次整理使用新仓库和干净提交历史，发布集合不含原运行环境的配置、备份或历史 Git 对象。

## 配置与凭据

- 环境变量与本地 `.env` 用于配置密钥，示例文件只提供变量名。
- 本地 `desktop/bot-config.json` 不提交，公开模板是 `bot-config.example.json`。
- 手机的健康端点和令牌保存在使用者手机的配置里，默认推送关闭。
- 手机签名文件、Windows 账号绑定和运行状态由使用者在自己的环境生成。
- 日志和模型记录应屏蔽认证信息；请仍按私人文件管理其内容。

## 数据流

| 数据 | 去向 |
| --- | --- |
| 微信输入与所需的对话上下文 | 你配置的模型服务 |
| 生成的回复 | 你配置的微信聊天对象 |
| 手环读数与设备状态 | 你在手机设置的电脑健康端点 |
| 模型输入、返回和处理诊断 | 本地数据存储与本机看板 |
| 构建与运行状态 | 本地日志和状态文件 |

启用模型服务意味着该服务会收到请求中提供的内容。可以关闭不使用的图片、语音、视频、主动发言和健康功能。

## 记忆与会话隔离

记忆以会话归属；成员事实保留稳定成员标识和显示称呼。旧的未归属承诺保留在单独列表，不猜测归属，不把过去的年份改成未来日期。过期记录不会冒充新的待兑现承诺。

手动保存和后台压缩共用写入保护。修改前的备份同样属于私人数据，不能随源码发布。

## 发布检查

`tools/privacy_check.py` 检查已知密钥格式、个人机器路径、签名材料和运行文件。`--staged` 检查 Git 索引里的实际 blob，避免只检查工作树。

扫描是辅助措施。私人叙述、聊天截图、设备导出和新格式的密钥仍需要人工复核。仓库中的测试数据应清楚标为合成样例，不能从个人数据库提取后当作样例提交。

Gadgetbridge 上游自带的公开测试资源和第三方版权说明依原许可证保留，与运行者在手机上生成的数据分开管理。
